# Byte Vue Monitor 需求与验收

本分支把原有 Vue 监控原型完善为可安装、可运行和可验证的 SDK。错误、性能、路由停留三条采集链路已实现，并提供本地接收器、Vue 示例、回归测试与 CI 配置。交付范围为 SDK 和本地验证环境，不包含生产后台或数据存储。

具体提交区间、验证记录及至少五条后续工作见 [Milestones](MILESTONES.md)，安装和 API 见 [README](../README.md)。

## 项目范围

本项目包含错误、性能、路由停留三个功能子系统，以及统一上报、参数脱敏、本地接收器、Vue 示例、测试和 CI。后续 TODO 均对应具体模块，见里程碑文档。

本分支 `codex/monitor-functional-history` 是对已有实际开发提交的整理：文档、图片和锁文件归入相关功能提交。原分支和备份保留，未将整理工作表述为新增功能。当前源码及测试与整理前一致。

原型的主要问题包括包配置缺失、上报地址为空、复用 XHR、监听移除不匹配、堆栈只保留末帧、性能无限等待和失败导航误计时；下面的需求对应实际修复及可运行验收。

## 已实现的可验收需求

### R1 可安装工程与接入示例

包元数据、相对导入、锁定依赖、构建和验证脚本已经建立。Vue 示例从公开入口导入 SDK，本地接收器展示真实请求。

验收：干净安装后执行 README 命令可运行；三条采集链路均到达接收器。对应 `package.json`、`index.js`、`example/` 和浏览器用例。依赖安装、SDK 构建及示例构建均通过。

### R2 可配置且互不干扰的上报

endpoint 必填且校验协议和内嵌凭据，每次 fetch 独立管理 AbortController；超时、网络失败和 500 响应返回状态。默认不打印载荷，移除 URL 凭据、片段、查询参数及未允许的路由参数。同步 beforeSend 支持额外过滤，之后再次执行默认脱敏。

验收：真实 HTTP 接收器收齐 10 个并发事件；超时、HTTP 失败、过滤器异常、循环对象、beacon 回退、白名单与销毁行为通过测试。对应 `utils/tracker.js`、`utils/privacy.js` 和 `tests/tracker.test.js`。

### R3 健壮的错误采集

采集 JavaScript、Promise、Vue 和资源加载错误；兼容字符串、对象、null 等拒绝原因及缺少 stack 的情况。逐帧解析 Chrome 和 Firefox 形态堆栈，组件实例缺失时降级。交互路径不修改输入数组，不包含按键、输入值或 DOM 标识信息。

验收：真实浏览器四种错误均到达接收器；错误输入不触发二次异常，多帧结果保留。对应 `lib/useErrorMonitor.js`、错误与交互工具、`tests/errors.test.js` 和浏览器错误用例。

### R4 有限等待的性能采集

检查 PerformanceObserver 能力；导航和资源使用各自条目。默认 5 秒后报告已有结果，缺失指标为 null 并保留原因，不等待首次输入无限轮询。LCP 候选和晚到输入可更新；页面隐藏或离开时结束观测。排除接收器请求，限制每次启动的资源事件数量。

验收：无交互和不支持指标时按时产生部分结果；LCP 可更新；资源及导航耗时独立且为数值；停止后无回调上报或计时器残留。对应 `lib/usePerformance.js`、`tests/performance.test.js` 和浏览器无交互用例。

### R5 准确的路由停留时长

在成功导航之后结算上一页；忽略首次占位路由、取消导航和同 path 参数变化。使用单调时钟，时长包含后台停留。pagehide、主动停止和 BFCache 恢复有明确语义；守卫可以注销。

验收：可控时钟下 A 页 1000 ms 后进入 B，结果为 1000 ms；取消导航不重置；pagehide 与 stop 不重复结算；旧 isReady 回调不干扰重启。真实 Vue Router 联调通过。对应 `lib/usePageDuration.js` 和 `tests/duration.test.js`。

### R6 可停止和重新启动的生命周期

每个实例独立拥有监听、observer、路由守卫和计时器。重复启动和停止安全；Vue 原处理器保留并链式调用，仅在 SDK 仍拥有配置时恢复。仅导入模块不访问 DOM；SSR 启动返回 false。

验收：重复启停后只上报一次，停止后无残留监听；宿主替换的处理器不被覆盖。各 hook 测试及真实浏览器停止、重启用例均覆盖。

### R7 与代码一致的文档和质量验证

README 包含环境、安装、启动、完整接入、API、载荷、指标定义、清理、构建、测试和局限。CI 从锁定依赖安装，执行相同检查、测试、构建及 Chromium 联调。

验收：本地重新安装依赖后全套验证通过；测试覆盖统计仅包含 lib 和 utils；源码解析与实际功能验证分开记录。Chrome 已实测，未宣称其他浏览器已经验证；CI 远端执行状态单独核实。
